PaperReader 设置

「帮我读」会用选定的本地 AI CLI，在下面的 vault 里运行 paper-reading 技能。

隐私提示：精读会把论文内容与提示发送给所选 CLI 服务。Codex 任务默认拒绝读取本机文件，仅开放最小运行时、内置技能、Python、所选 vault 中除 .obsidian 外的内容和 App 缓存；这些 vault 内容与缓存可写并允许联网，但 .obsidian 配置/插件、$CODEX_HOME、SSH、PaperReader 设置和无关用户文件不可读。该权限配置仍是 beta 级纵深防御，不是完整 OS 隔离。Claude/Trae 使用各自的非交互 bypass 模式。PaperReader 本身不做遥测，也不收集或保存 AI provider 凭据；登录由各 CLI 自己管理。
请按 Codex CLI 官方指南安装，并先在终端用 ChatGPT 或 Codex CLI 支持的 API 认证完成登录；不要把该凭据粘贴到 PaperReader。
论文抽取依赖该解释器可导入 PyMuPDF（fitz）。自动探测失败时，在这里指定已安装 PyMuPDF 的 python 可执行文件。
app 启动直接从这里拉最新论文，无需 git pull；抓取失败自动回退缓存/内置快照。
在 Zotero 官方页面创建 key，并允许访问个人文献库（读/写）。PaperReader 只在本机系统安全存储加密后保存；输入框不会回显已保存的 key，留空也不会将它清除。
必须与 Zotero 设置中的 “Linked Attachment Base Directory（链接附件基准目录）” 完全一致。
模型列表来自本机 Trae CLI，负载越低越不容易排队卡住。
