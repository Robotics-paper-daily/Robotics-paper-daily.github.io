## External services and applications

The following are not bundled libraries and are not operated by this project:

- arXiv provides paper metadata, HTML, PDFs, and source links;
- Zotero provides the Web API and metadata synchronization;
- Microsoft OneDrive/macOS File Provider synchronizes linked PDF bytes;
- Obsidian opens and optionally synchronizes the user-selected vault;
- [OpenAI Codex CLI (`codex`)](https://developers.openai.com/codex/cli/), Claude
  Code/Anthropic, and TraeCode are optional AI providers whose local CLIs
  connect to their own services and terms. PaperReader does not collect or save
  their credentials; Codex uses the ChatGPT/API authentication managed by its
  own local CLI. TraeCode remains available only to users who independently
  received a supported CLI build and account;
- DeepSeek (or a configured compatible endpoint) scores papers in the publishing
  workflow; and
- [hjfy.top](https://hjfy.top) provides outbound bilingual-reading links.
